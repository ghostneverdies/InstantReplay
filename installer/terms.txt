THIRD-PARTY COMPONENTS
----------------------

The application bundles FFmpeg shared libraries from the pinned gyan.dev GPL
5.1.2 build. They are stored in the application's engine\encoder folder and loaded
locally by the recording engine. The installer does not download FFmpeg.
FFmpeg source, build configuration, and license information:

https://ffmpeg.org/download.html

INSTALLATION AND PRIVACY
------------------------

The installer adds application files, uninstall registration, optional
shortcuts, and—when selected—a per-user start-with-Windows entry. Uninstalling
removes those items. Settings and recordings are retained unless the user
explicitly chooses to remove recordings.

Instant Replay records screen and audio locally. Footage is written to disk
only when a replay is saved. The application contains no telemetry or
analytics. Update checks contact the project's GitHub Releases endpoint.
